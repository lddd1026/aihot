## 内容范围（开发者向）

**只收录开发者关心的内容**：

| ✅ 收录 | ❌ 不收录 |
|---|---|
| 模型能力突破与发布（含开源模型） | 硬件资讯：显卡/晶圆/数据中心/液冷/散热/算力基建 |
| 爆火的开源工具、框架、开发工具 | 公司间商业消息：融资/收购/合作/财报/人事变动 |
| 研究突破与工程实践（训练/推理/评测/压缩等） | 政策监管、活动报名、招聘、课程促销 |
| 论文精选（每天 ≤2 篇） | 纯营销内容 |

实现为**三道过滤 + 一层排序加权**（规则预筛 → LLM 语义判定 → 日报组装排除；排序权重对技术类加权、对商业/硬件类压负分）。
判定口径写在 `pipeline.prefilter.exclude_keywords`（可追加）与 `pipeline.rank.interest_bonus`（可调，**整体替换、建议列全分类**）。
